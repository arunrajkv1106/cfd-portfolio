# CFD Portfolio

Computational fluid dynamics case studies in **ANSYS Fluent** — each a complete
workflow from geometry and meshing through **verification** (convergence, y⁺,
mesh independence) to **validation** against published data.

The emphasis is on *demonstrating trustworthy results*: not just running a
simulation, but showing the verification and validation that make the numbers
defensible.
